## 4. Recommended Strategy: `lgen_crash_protected_upper`

### 4.1 Logic

**Entry conditions (all must be true):**
1. Price ≤ Bollinger Band Lower (20, 2) — stock is oversold
2. RSI(14) < 35 — momentum confirms oversold
3. CCI(20) < -100 — extreme negative deviation
4. GARCH volatility forecast is NOT rising — volatility not accelerating (safe to buy)
5. **Crash filter:** Price did NOT drop >10% in the last 20 days — avoids catching falling knives during crashes

**Exit condition:**
1. Price ≥ Bollinger Band Upper (20, 2) — full mean-reversion range captured

### 4.2 The Crash Filter Innovation

The crash filter is the key innovation that makes this strategy superior:

- **Before crash filter** (`dividend_meanrev`): 113.24% return, 52.48% drawdown — the 2020 COVID crash caused three consecutive -20%, -17%, -15% losses over 96 days
- **After crash filter** (`lgen_crash_protected_upper`): 115.17% return, 23.21% drawdown — the same crash entries are skipped entirely

This is remarkable: **skipping bad entries both reduces risk AND increases return.** The crash filter eliminates the worst trades while keeping all the good ones, resulting in higher Sharpe (0.67 vs 0.50), lower drawdown (23% vs 52%), and higher return (115% vs 113%).

**Logic:** Same entry as `lgen_crash_protected_upper` (BB Lower + RSI<35 + CCI<-100 + GARCH filter), **but without the crash filter** → Exit at **BB Middle** OR **5-day high - 3×ATR trail** (whichever triggers first).

**Trade-off with `lgen_crash_protected_upper`:** Lower return (63.50% vs 115.17%) but **one-third the drawdown** (14.66% vs 23.21%) and **higher win rate** (86.4% vs 78.9%). The dual-exit mechanics provide better risk control per trade, at the cost of not capturing full-range moves to BB Upper.

**Note:** The crash filter was NOT included in `dual_exit_div_meanrev` — this strategy has a 48.31% drawdown when run on the full 20-year dataset (which includes the 2008 crisis). On the 10-year period (2016-2026), it performs well at 14.66% DD because the COVID crash was the primary source of drawdown.

### 8.2 Key Risk Factors

1. **2008-style crash:** The 20-year price range (23-318) shows LGEN has survived major crashes. The crash filter specifically addresses this risk. Without the crash filter, the strategy would have been vulnerable during 2008 (which is why the full 20-year backtest shows higher drawdowns).

2. **Extended bear market:** If LGEN enters a secular downtrend (like 2007-2011), BB mean-reversion entries would repeatedly catch falling knives. Mitigation: the GARCH filter avoids entries when volatility is rising, and the RSI/CCI thresholds ensure deep oversold conditions.

3. **Low signal environment:** In strong uptrends, BB Lower signals may never fire. The strategy only acts when opportunities exist — this is not a risk per se.

4. **Strategy concentration:** All winning strategies use the same basic entry logic (BB Lower + RSI + CCI). This means they all share the same systemic risk — if LGEN.L's mean-reverting behavior breaks down, all these strategies would fail simultaneously.

## 9. Implementation Guidance

### 9.1 Entry Checklist (`lgen_crash_protected_upper`)

```
✓ Close ≤ Bollinger Band Lower (20, 2)
✓ RSI(14) < 35
✓ CCI(20) < -100
✓ ta_garch_vol ≤ yesterday's ta_garch_vol  (volatility not rising)
✓ 20-day return > -10%  (crash filter — skip if price dropped >10% in 20 days)
```

**If all 5 conditions are true:** Enter long position with 100% of available cash.

### 9.2 Exit Rules (`lgen_crash_protected_upper`)

```
WHEN Close ≥ Bollinger Band Upper (20, 2) → EXIT (full profit capture)
```

### 9.3 Conservative Alternative Entry Checklist

```
✓ Close ≤ Bollinger Band Lower (20, 2)
✓ RSI(14) < 35
✓ CCI(20) < -100
✓ ta_garch_vol ≤ yesterday's ta_garch_vol

```

```
  1. Close ≥ Bollinger Band Middle (20) → EXIT (profit target)

  2. Close < (5-day High − 3 × ATR(14)) → EXIT (trailing stop)
```

- **Minimum cash buffer:** 2% of portfolio for slippage

### 9.6 Monitoring & Review

- **Review entry signals:** Weekly (check if conditions are being met)
- **Review exit triggers:** Daily (ensure position is tracked correctly)

- **Annual review:** Verify that BB/RSI/CCI parameters remain optimal
