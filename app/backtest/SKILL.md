# Investment Strategy Optimizer Skill

## Description

This skill analyses technical analysis outputs generated by `stock-market-ta-local` and determines:

- Current market regime
- Optimal trading/investment strategy
- Investment rating
- Confidence score
- Risk level
- Position sizing
- Entry and exit conditions

The objective is not to predict the future, but to identify the most appropriate strategy for the current market environment.

---

## Inputs

```yaml
inputs:
  - ticker
  - market_data_csv
  - stock_info
  - optional_sector_data
  - optional_macro_context
```

---

## Outputs

```yaml
outputs:
  - investment_rating
  - recommended_strategy
  - confidence_score
  - trade_direction
  - supporting_evidence
  - risk_assessment
  - entry_conditions
  - exit_conditions
  - stop_loss
  - position_size
  - expected_market_regime
```

---

## Core Philosophy

The skill must never rely on a single indicator.

Instead, every decision should be based on:

```text
Regime
+
Trend
+
Momentum
+
Volume
+
Volatility
+
Market Structure
=
Investment Decision
```

---

# Evaluation Workflow

## Priority Hierarchy

Evaluate data in the following order:

```text
1. Regime
2. Trend
3. Market Structure
4. Momentum
5. Volume
6. Volatility
7. Relative Strength / Valuation
```

### Rationale

```text
Wrong Regime
=
Wrong Strategy

Correct Regime
+
Correct Confirmation Signals
=
Higher Win Rate
```

# Step 9 – Composite Investment Score

## Weighted Scoring Model

```python
investment_score = (
    trend_score * 0.25
    + momentum_score * 0.20
    + volume_score * 0.15
    + structure_score * 0.20
    + volatility_score * 0.10
    + rs_score * 0.10
)
```

## Rating System

```text
90-100 = Strong Buy
80-89  = Buy
70-79  = Accumulate
60-69  = Watchlist
40-59  = Hold
20-39  = Reduce
0-19   = Sell
```

# Risk Management Engine

## Position Sizing

```python
risk_per_trade = portfolio_value * 0.01

position_size = (
    risk_per_trade /
    (2 * atr14)
)
```

---

## Stop Loss Rules

### Trend Following

```text
Stop Loss = Entry - (2 × ATR)
```

### Breakout Strategy

```text
Stop Loss = Entry - (2.5 × ATR)
```

### Mean Reversion

```text
Stop Loss = Below Support
```

---

## Profit Taking

Minimum:

```text
Reward/Risk >= 2:1
```

Preferred:

```text
Reward/Risk >= 3:1
```

# Final Principle

The model should not attempt to predict the future direction of a stock.

Instead, it should answer:

```text
1. What market regime exists?
2. Which strategy is best suited for that regime?
3. What is the quality of the setup?
4. Is the risk/reward favourable?
5. What position size should be used?
```

This transforms the system from a simple signal generator into a professional-grade strategy selection and portfolio decision engine.
